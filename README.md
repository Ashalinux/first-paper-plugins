# First Paper Plugins

**My very first steps in Minecraft plugin development – small Paper plugins I wrote while learning Java.**

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Paper](https://img.shields.io/badge/Paper-0A84FF?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-3D3929?style=for-the-badge)

<br />

Everyone starts somewhere. These are tiny, beginner-friendly plugins – a good reference if you're learning plugin development yourself.

## Contents

| Folder | What it does | Build |
|:--|:--|:--|
| `first-minecraft-plugin` | The classic "hello world" plugin | Gradle |
| `minecraft-plugin` | Basic plugin setup with Gradle | Gradle |
| `plugin` | Minimal plugin skeleton | Maven |
| `jumplistener` | Sends a message every time a player jumps | Maven |
| `a-minecraft-plugin` | Plugin with its own jump listener | Maven |

<br />

## Building

Open a folder and run `mvn package` or `./gradlew build`, depending on the project.
